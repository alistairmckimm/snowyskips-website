# Snowy Skips website

Source for **snowyskips.com.au**, the website for Snowy Skips: skip bins, equipment hire and labour hire across the Snowy Monaro (Berridale NSW). A McKimm Civil Pty Ltd business.

- `index.html` is the whole site (one page with a menu).
- `img/` holds the photos and the Skip Bin Guide PDF.
- This is the **live** build, served at https://snowyskips.com.au (the `CNAME` file sets the domain).

Never put passwords, API keys or other secrets in this repository: it is public.
